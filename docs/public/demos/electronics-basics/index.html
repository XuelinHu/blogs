断电测量顺序

①
切断电源拔掉电源并等待
②
确认放电用合适方法释放储能
③
检查表笔插孔、档位、量程正确
④
测量与复核结合原理图和 BOM
⚠通断档发出蜂鸣不等于“绝对零欧姆”，在线测量还会受到并联支路影响。对未知高压设备不要自行测量。
