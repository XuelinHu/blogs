# Java

这里收录 Java、JVM、并发编程与语言机制相关笔记。

## 1. 分类说明

Java 分类用于整理 Java 语言基础、集合、并发、JVM、运行时诊断和编码规范。内容面向后端开发与面试复习，重点关注底层原理、源码结构和实际排查方法。

## 2. 内容范围

- 集合、对象模型、SPI、泛型、关键字等语言机制。
- JVM 内存模型、类加载、垃圾回收、直接内存和 Arthas 等调优诊断工具。
- JUC、锁、线程池、ThreadLocal 等并发编程主题。
