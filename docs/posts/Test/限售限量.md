# 1. 释义

- 限量：只能买设置好的量
- 限售：只能卖设置好的量

# 2. 社区团购业务的限售限量

- 用户限量：一天一个sku的用户限量
- 门店限量
- 分区限量
- 指定门店限量
- 指定区域限量
- 商品组合限量
- 商品限售规则
- 多商品门店限量

# 3. 设计时关注点

- 口径统一：下单限量、支付限量、履约限量的口径必须先定义清楚。
- 维度清晰：是按用户、门店、区域、活动还是商品组合做限制。
- 并发一致性：高并发场景下要避免超卖或重复占用。
- 回滚机制：取消订单、支付超时、履约失败时要不要返还额度。

# 4. 测试要点

- 正常购买是否在阈值内通过。
- 达到上限后是否被正确拦截。
- 并发下是否出现超量成功。
- 多维规则叠加时优先级是否正确。
- 退款、取消、超时后额度是否按预期恢复。
