# 1. 概述

SkyWalking 是面向分布式系统的可观测性平台，常用于链路追踪、服务拓扑、性能指标采集和慢调用定位。接入时通常需要关注 Agent 版本、服务名、采样策略、后端存储和 Trace 与日志的关联。
