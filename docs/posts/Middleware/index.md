# Middleware

这里收录消息队列、注册协调、链路追踪与可观测性相关笔记。

## 1. 分类说明

Middleware 分类用于承接不直接属于 Spring 框架本身、但在后端系统中高频使用的基础中间件内容。这里的笔记更关注组件原理、使用方式、面试复盘和排障经验。

## 2. 内容范围

- Kafka、RocketMQ 等消息队列与异步通信机制。
- Zookeeper 等协调服务、注册发现和分布式一致性组件。
- SkyWalking 等链路追踪、服务拓扑和可观测性工具。
