# 1. free-cad

- 默认的Cache路径 /Users/${username}/Library/Caches/FreeCAD/Cache/
- 默认的宏路径 /Users/${username}/Library/Application Support/FreeCAD/Macro
- 默认会安装一个python /Applications/FreeCAD.app/Contents/Resources/bin/python

## 1.1. 适用场景

FreeCAD 适合做轻量 3D 建模、参数化设计和脚本化建模，尤其适合需要结合 Python 做自动化处理的场景。

## 1.2. 常用目录

- Cache 路径：`/Users/${username}/Library/Caches/FreeCAD/Cache/`
- 宏路径：`/Users/${username}/Library/Application Support/FreeCAD/Macro`
- 内置 Python：`/Applications/FreeCAD.app/Contents/Resources/bin/python`

## 1.3. 使用建议

- 如果要写自动化脚本，优先确认使用的是 FreeCAD 自带 Python 还是系统 Python。
- 宏脚本建议单独归档，避免重装后丢失。
- 插件或工作台较多时，注意区分用户配置和应用目录。
