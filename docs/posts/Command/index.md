# Command

这里收录常用命令、环境配置、开发工具与排障记录。

## 1. 分类说明

Command 分类用于沉淀日常开发、运维、系统安装和工具配置中高频使用的命令。内容以可复制执行、快速定位问题为主，适合作为个人命令手册和环境配置手册查询。

## 2. 内容范围

- Git、Docker、Linux、Maven、Gradle、Conda、LaTeX 等常用命令。
- IDE、终端、系统工具、新机安装和开发环境配置。
- 网络代理、端口排查、进程分析和基础故障处理记录。
