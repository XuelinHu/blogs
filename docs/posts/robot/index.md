# 机器人与具身智能

这里收录机器人学、运动控制、视觉、标定、遥操作与仿真实验相关的学习记录。

## 内容范围

- 坐标系、旋转与平移、齐次变换和矢量运算。
- 正运动学、逆运动学、`ikpy` 及机械臂控制。
- 相机标定、手眼标定、机器人标定与误差分析。
- OpenCV 目标检测、跟踪、数据集扩展和评估。
- 同构遥操作、机器狗步态算法和 HTML 交互式模拟器。
- ROS2 工作空间、Topic 通讯、机械臂驱动、视觉控制与语音 AI。
