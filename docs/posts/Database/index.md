# Database

这里收录数据库、缓存、检索与存储系统相关笔记。

## 1. 分类说明

Database 分类关注数据存储、查询性能、事务一致性、缓存设计和检索系统。内容兼顾基础原理与业务排查，适合复习数据库核心概念和整理线上问题处理思路。

## 2. 内容范围

- MySQL 锁、事务、索引、常用 SQL 和性能优化。
- Redis、Redisson、缓存一致性与分布式锁相关实践。
- Elasticsearch、数据仓库、数据湖等存储与检索主题。
