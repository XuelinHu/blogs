# 电工基础

这里从电压、电流、电阻和功率开始，逐步认识电阻、电容、电感等常见元器件，并用可交互的 HTML/SVG 实验把公式变成可以拖动和观察的曲线。

::: danger 注意：本专题只使用安全特低电压进行教学
初学实验建议使用带限流功能的 `3.3 V～12 V` 直流电源。不要拆解市电设备，不要触碰插座内部，也不要把面包板、万用表电流档或普通示波器探头直接接到 `220 V` 市电。
:::

## 学习路线

1. 先分清电压、电流、电阻、功率和能量。
2. 学会识别电阻色环、贴片阻值和额定功率。
3. 观察电容电压不能突变，以及 RC 充放电曲线。
4. 观察电感电流不能突变，以及 RL 电流曲线。
5. 最后再学习二极管、三极管、MOSFET、运算放大器和电源电路。
